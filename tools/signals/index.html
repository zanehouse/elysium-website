Smart-Money Signals

One composite read on where informed money is leaning for a single name, built from insider buying, options positioning, and the dealer gamma regime. Every input comes from data already published on this site.

Recent Congressional Filings

Market-wide House Periodic Transaction Reports. These are shown as context rather than scored per ticker, since the House publishes no machine-readable ticker or amount, only the linked PDF. The Insider Trades tool carries the full feed.

    Smart-Money Composite runs 0 for strongly bearish to 100 for strongly bullish, taken as the mean of whichever component scores are available below. Insider Buying is net dollar value bought against sold in SEC Form 4 filings over roughly the last 180 days, counting open-market and disposition transactions that carry a stated value and ignoring option exercises priced at $0. It is available only for the fully-parsed names highlighted above. Options Positioning maps the near-the-money put/call open-interest ratio to a bullish or bearish score, where heavier call interest reads bullish, using the same scale as the Macro dashboard's put/call sentiment. Gamma Regime reads net dealer gamma off the same option chain as the GEX tool: net-positive gamma means dealers are long and is treated as stabilizing, which scores higher, while net-negative gamma is amplifying and scores lower. Any component without enough data behind it shows as "—" and drops out of the composite rather than getting guessed at. Options coverage spans roughly 60 large caps, and full insider detail covers the highlighted names. Data is delayed and published for informational and educational purposes only.
